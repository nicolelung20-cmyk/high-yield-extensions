# Email Finder Pro - Chrome Extension

## Features
- 📧 Find business emails from LinkedIn profiles
- 🔍 Domain-wide email search
- ✓ Email verification
- 🎯 High accuracy with multiple APIs
- 📊 Search history and analytics
- ⚡ One-click LinkedIn integration
- 🔐 Secure API key storage

## Installation

1. Clone this repository
2. Open `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked"
5. Select this folder

## Setup

### Get API Keys

**Hunter.io:**
1. Go to https://hunter.io
2. Sign up and get API key
3. Paste into extension settings

**Clearbit:**
1. Go to https://clearbit.com
2. Sign up and get API key  
3. Paste into extension settings

## Usage

### On LinkedIn
1. Visit any LinkedIn profile
2. Click "📧 Find Email" button
3. Extension auto-detects company domain
4. Shows email with confidence score

### In Extension Popup
1. Enter first name and domain
2. Click "Find Email"
3. Results appear with verification option
